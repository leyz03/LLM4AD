# HypoEvo 真实模型 pilot

模型：`qwen3.5-flash`；TSP-50 / CVRP-50；每次运行 28 次调用。
任务评估为均匀随机构造基准，不是 TSPLIB/CVRPLIB；平均路径长度越低越好。
训练 16 个实例、独立测试 64 个实例；按训练分数选出一个算法后才评估测试集。

## 解释范围

- 三个搜索种子的 pilot，不据此声称统计显著性或普遍优越性。
- 等调用次数不等于等 token / 等候选数量；反思和摘要调用均计入预算。
- EoH 使用原始初始化，HypoEvo 从公共最近邻种子开始，属于完整方法对比。
- 种群只按搜索集选择，负例是配对回退或执行失败，不构成机制因果证明。
- 两轮格式诊断及一次 12 调用的 API 中断运行被排除，计入 budget_audit.json；不与正式结果混合。
- 不完整运行保留在 runs.csv，不计入完成运行的均值。
- runs.csv 记录实际算子次数、分区数和摘要版本；summary_version=-1 表示摘要缓存未成功更新。
- 格式解析失败照常消耗预算；本批次未在观察分数后修改搜索代码。

## 完成情况与诊断

18/18 组完成，正式 HTTP 请求 504 次，正式批次总 token 1,082,783。包含两轮诊断和一次接口中断后的重跑，总请求数保守上限为 540 次。模型为 qwen3.5-flash。

HypoEvo 两项任务的均值均未超过 EoH。按同种子相对差异取平均，TSP 比 EoH 差 1.97%，CVRP 差 0.63%；相对关闭记忆，TSP 差 0.20%，CVRP 改善 0.91%。

- HypoEvo 合法候选 51/96（53.1%），EoH 为 118/166（71.1%），关闭记忆为 42/114（36.8%）。不同方法调用用于生成、反思、摘要的比例不同，因此候选数不同。
- HypoEvo 的 45 次无效候选中，39 次是缺失 concept 或 hypothesis；格式遵循是本轮重要瓶颈。
- HypoEvo 六次运行中三次未成功更新摘要缓存。原始试验记录仍可用于检索，不能据此等同于完全没有记忆。
- 关闭记忆的六组最终均保留公共最近邻种子。CVRP 的记忆收益只出现在一个种子，不能据此声称稳定有效。
- HypoEvo 总 token 639,168，EoH 为 196,702，关闭记忆为 246,913；当前尚不具备成本优势。
- 本次测试可支持流程可运行与瓶颈诊断，不能支持显著领先的论文或简历表述。

后续优先改进结构化输出与摘要事实校验，再做新的预设实验；不要利用当前测试集选择提示词或算法。
