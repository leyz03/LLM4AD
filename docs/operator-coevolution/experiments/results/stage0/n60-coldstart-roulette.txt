# Stage 0 raw output: coldstart, roulette selection (--n-repeat 60, matches implementation-plan.md E3 table)


==============================================================================
  E3  新算子冷启动: 剪枝误杀 与 先验收缩的价值
      场景: 跑 n_steps 后把 3 个最差算子替换成真实质量在 85 分位的新算子,
            再跑 n_steps//4 (新算子只拿到很少样本), 然后按分数剪掉最差 3 个
==============================================================================

  新算子真实质量位于 85 分位, 却被剪枝误杀的比例 (越低越好):

  [A] 估计器对比
    F 累加   (G-LNS 原方案)                94%   <- 新算子几乎必被误杀
    F 均值   (频率去偏)                    44%
    ANOVA alpha_hat                        23%   <- 跨伙伴维度借统计强度

  [B] 在 ANOVA 之上再向先验收缩 (kappa=8)
    先验与真实质量的相关性                     误杀率
    rho ~ 0.0  (无先验/收缩向 0)             16%
    rho ~ 0.3                          18%
    rho ~ 0.5                           9%
    rho ~ 0.7                           4%
    rho ~ 0.9                           3%

  解读:
    1) 累加式 F 与'被选中次数'几乎同义, 新算子样本少 => 排名垫底 => 被误杀。
       G-LNS 用'每代清零 F 和 S'来打补丁, 代价是丢掉全部跨代信息。
    2) 改成均值只解决一半; **方差分解**才是真正的解 —— 因为它能跨伙伴维度
       借统计强度: 新破坏算子的少量样本会按'碰到的是哪些修复算子'做校正。
       这是支持 alpha+beta+gamma 分解的第三个独立论据 (前两个见 E1/E2)。
    3) 再叠一个信息性先验还能继续降低误杀 —— 这给'探针语义指纹 / LLM 语义先验'
       一个可量化的价值靶子: 先验需要多准才值得你去实现。
