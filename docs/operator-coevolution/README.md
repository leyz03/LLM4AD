# 算子协同进化研究材料

本目录汇总在 LLM4AD 上开展 destroy-repair 算子协同进化研究所需的调研、实施方案和 Stage 0 验证材料。

## 文档导航

- [跨领域调研与迁移设计](./literature-review.md)：梳理算子距离、行为新颖性和信用分配方法，并给出可迁移设计。
- [落地实施方案](./implementation-plan.md)：记录 Stage 0 结论、架构约束、分阶段路线与实验优先级。
- [Stage 0 实验](./experiments/)：包含信用估计器验证脚本、运行说明和已保存结果。

## 推荐阅读顺序

1. 先阅读跨领域调研，理解距离度量和信用分配的设计空间。
2. 再阅读实施方案，了解已验证结论和后续阶段安排。
3. 最后按实验说明复现 Stage 0，核对基线结果。
